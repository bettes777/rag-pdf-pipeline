# Source documents

The PDFs are not stored in this repository (one is about 30 MB, and they are published by their owners). Download them and save them in this folder with the file names below, which the notebook looks for.

| Save as | Document | Source |
|---|---|---|
| `nisti_ai_rmf.pdf` | NIST AI Risk Management Framework (AI RMF 1.0), NIST AI 100-1, January 2023 (48 pages) | [NIST publication page](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10) |
| `un_scientific_panel_ai_preliminary_report.pdf` | Preliminary Report of the Independent International Scientific Panel on AI, July 2026 (59 pages) | [UN Scientific Panel report page](https://www.un.org/independent-international-scientific-panel-ai/en/preliminary-report) |
| `undp_digital_strategy.pdf` | UNDP Digital Strategy 2022-2025 (52 pages) | [UNDP Digital Strategy page](https://www.undp.org/digital/digital-strategy) |

The notebook's chunk counts (309 in total) depend on these exact versions. A different edition will give different numbers.
